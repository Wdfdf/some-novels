## 从神令使

| 人名 | 身份 | 介绍 |
|---|---|---|
| 程实 | 欺诈令使 | 名号【愚戏】。【欺诈】亲自拔擢的令使，靠着"从不骗人"的谎言体系起家，布局夺走湮灭神座、推凡人朋友登神位，最后自己成新【源初】。 |
| 希望之火 | 命运令使 | 命运留下的"变数"，传火者组织的庇佑神。命运开局被源初抹杀后作为遗产存在。结局秦薪以身为柴补神座缺漏，"星火易逝，传火不息"——火的意义是传希望，不是占神座。 |
| 歌莉丝 | 诞育令使 | 名号【罪殖巢母】，诞育的第一个孩子，信徒称"祂的戒鞭"。诞育的惩戒代行者，亲手抓走并处死亵渎诞育的0221。跟污堕侧的阿夫洛斯是同一存在的一体两面。 |
| 永恒之日 | 诞育令使 | 诞育神系大令使，公开资料无真名记载。钦定胡璇为继承人——胡璇结局正是登神【诞育】接的他的班。与胡璇关系亲密，程实生日贺词称他"胡璇的朋友兼接生者"。 |
| 卢西亚 | 诞育从神 | 名号【诞嗣圣音】，后期剧情登场的诞育从神，百科名录在册，公开资料记载少，戏份不多。 |
| 芙拉卓尔 | 繁荣令使 | 繁荣之母长女，被母亲同化共生，成为繁荣的一部分。她的身份和命运被红霖继承——红霖结局登神【繁荣】接的就是这个位置。 |
| 赫拉祖尔 | 繁荣令使 | 繁荣之母长子，跟姐姐芙拉卓尔一样被同化共生。繁荣家四兄妹里最低调的背景板，几乎没独立戏份。 |
| 迦楼罗 | 死亡令使 | 名号【骨之屠夫】，死亡最信任、追随最久的令使。深爱乐乐尔但求而不得，最终为了替她承担与繁荣同化的命运自己顶上，从死亡阵营变成繁荣的一部分——全书最惨烈的从神。 |
| 德拉希尔科 | 污堕令使 | 名号【无欲之罪】，污堕第一令使，"世间第一位恶孽"，佝偻黑袍图腾脸。全书信息量最大的令使之一：洞察欲海里【污堕】就是【源初】的真相后自灭，死前收走神选毒药的欲望作警告；本体"黑龙王"在彼梦我魇被李景明释放，第1181章公约列会投出关键一票。 |
| 阿夫洛斯 | 污堕令使 | 名号【欢欲之门】，与诞育侧的歌莉丝一体两面，卡在欲海那一侧。"意外"通过实验解放过王为进，还让胡璇吃过醋。 |
| 特莉雅 | 污堕从神 | 名号【悲悯领主】，百科名录在册，名号与污堕牧师职业同名呼应。公开资料少，属于"在册但背景板"。 |
| 尤格 | 腐朽令使 | 名号【腐鹫末王】，罗纳斯国皇帝，贼眉鼠眼、身材圆润，全书最丢人的从神。湮灭到来时背弃恩主带皇庭跑路（第567章），被程实追着打（第909章"猫抓老鼠"），欺软怕硬。 |
| 狄泽尔 | 腐朽令使（前繁荣令使） | 名号【无翳的华冠】，繁荣之母次子，为报复母亲跳槽腐朽。因想篡夺腐朽神位被赐死——躯体变荒芜行者、灵魂封进匕首【疮痍之赐】，南宫靠这把匕首起的家。 |
| 赫罗伯斯 | 湮灭令使 | 名号【净蠹之手】，湮灭最忠实的令使。被程实用"真实宇宙、湮灭即将消失"的说辞忽悠，亲自向【公约】请求继承湮灭神座（第1169、1174章）——至死喊着"从未背叛信仰"，却是程实夺湮灭神座最关键的那枚棋子。 |
| 乐乐尔 | 污堕令使（前繁荣令使） | 原名【欣荣的繁枝】，繁荣之母幼女。因母亲把哥哥姐姐同化共生的恐怖，主动跳入欲海堕落成【恐惧母树】。结局源初在欲海边种下繁荣枝丫，她守着欲海大门。 |
| 憎恶之怒 | 混乱令使 | 外貌是一轮巨日的混沌从神，名号常与"炽日"混用。被【秩序】囚禁后成了元素法官的最高威能——拉开牢门一瞬，压抑无数时光的怒火倾泻而下，混乱神的令使被秩序抓去当核武器用。 |
| 程实 | 混乱令使 | 名号【奥特曼】。全书唯一双令使之一，先当欺诈令使"愚戏"，后兼任混乱令使"奥特曼"，同时是【时间】亲手铸造的"第一根指针"，最终登顶新【源初】。 |
| 鸣雷 | 从神（归属未载明） | 第一次神战中被【秩序】击杀的背景板从神，目前只存在于神战史料里，没有独立戏份，也没有真名记载。 |
